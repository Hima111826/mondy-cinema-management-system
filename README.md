# 🎬 Mondy Cinema Management System

A PHP and MySQL-based web application designed to manage cinema operations, including movie management, customer accounts, bookings, payments, and administrative activities.

## 📌 Project Overview

Mondy Cinema Management System provides a web-based platform for customers to browse available movies, create accounts, make bookings, manage their reservations, and complete payments.

The system also provides an administrative interface for managing movies, users, bookings, messages, and payment-related information.

## ✨ Features

### 👤 Customer Features

- User registration and login
- User profile management
- Browse available movies
- View movie information
- Book movies
- Manage bookings
- Cancel bookings
- Payment processing
- View booking history
- Contact cinema administration

### 🔐 Administration Features

- Administrator authentication
- Admin dashboard
- Manage movies
- Manage users
- Manage bookings
- Manage payments
- Manage customer messages
- View and manage cinema information
